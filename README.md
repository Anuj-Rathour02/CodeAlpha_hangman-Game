# CodeAlpha_hangman-Game
A simple text-based Hangman game in Python. The player guesses a hidden word one letter at a time with a maximum of 6 incorrect attempts.

## Features
- Random word selection
- Letter-by-letter guessing
- Maximum 6 incorrect guesses
- Console-based gameplay

## Technologies Used
- Python
- Random Module

## Learning Concepts
- Lists
- Loops
- Conditional Statements
- User Input
- Random Module

Created as part of the CodeAlpha Python Programming Internship.
